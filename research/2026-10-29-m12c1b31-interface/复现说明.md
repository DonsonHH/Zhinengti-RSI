# 本轮复现入口

## 本地便携核对

在仓库根目录运行，Python3.11以上、NumPy即可，不需要本地Torch。输出路径使用新的文件名，防止覆盖原核验。

```powershell
$env:PYTHONPATH='src'
python scripts/verify_causal_stopping.py --workspace . --output .work/causal-preflight-review.json
python scripts/verify_queue_diagnosis.py --workspace . --output .work/old-b3-review.json
python -m unittest discover -s tests -p test_causal_stopping.py -v
```

第一个入口核对旧文件、最终受测源码、冻结协议、215项真实Torch证据、全部十个试跑原件、三条公开回归、数值分量、实际额度／重访和资源账本；本地没有Torch时不能把它说成重新运行了全部神经测试。第二个入口重做旧B3的728次排班核对。

## 真实Torch执行

`source/code-v6.tar.gz`与`code-v6-manifest.json`绑定最终全套源和本地已有案例。计算采用已存在的Torch2.6模块与旧冻结权重；权重位置和散列在试跑的`model-inputs.json`及旧M11清单中。不要因路径不存在就自动下载、换模型或训练。

集群正确工作目录下的两个入口为：

```bash
python scripts/test_causal_torch.py --output /new/path/tests
python scripts/audit_causal_preflight.py \
  --pilot /saved/path/pilot-v3 --output /new/path/pilot-audit.json \
  --actors /share/home/renly/renly-patrol-rsi/runs/20261027-m11/policies-v2 \
  --estimator-weights /share/home/renly/renly-patrol-rsi/runs/20261028-m111/frozen-estimator.pt \
  --estimator-manifest research/2026-10-28-m111-coverage/frozen_estimator.json
```

持续计算通过Slurm，显式申请CPU、内存和时限；不要在mu01登录节点执行完整套件或仿真。作业模板为`cluster/m12c1b31_preflight.sbatch`和`cluster/m12c1b31_audit.sbatch`。实际运行根目录为`/share/home/renly/renly-patrol-rsi/runs/20261029-m12c1b31`。

## 文件用途

- [公开时序审查](公开信息与时序接口审查.md)与[统一效用说明](CHECK-WAIT统一效用.md)：方法与来源定义。
- [冻结方案](正式实验冻结方案.json)：后续新的种子、候选、门槛和预算；v1副本用于保留早期语义。
- [回归与试跑](回归与试跑结果.md)、[Slurm成本](Slurm成本与执行计划.md)、[代码审查](代码审查.md)：正负结果与修复。
- [GO／NO-GO](GO-NO-GO判断.md)与[阶段状态](阶段状态.json)：本轮完成范围与后续决策。
- [本轮汇总](本轮汇总.json)：集中所有报告、关键机器结果及来源索引，可独立阅读。
- `evidence/cluster-v1`：初次失败日志与初次成功试跑；`cluster-reviewed`：审查修复后的最终试跑及中间审计；`cluster-final`：最终215项测试、独立审计与终态账本。

整份汇总含离线案例身份与实验结果，不能作为在线控制输入。部署控制只读取`causal-public-v1`白名单；真实异常窗口继续只归评价器与独立Oracle。
